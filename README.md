Dress Rental Planner
Про проєкт

Dress Rental Planner — навчальний проєкт для студії оренди одягу.

Проєкт допомагає вести облік замовлень, бачити майбутні оренди та не забувати вчасно підготувати або відправити посилку клієнту.

Мета проєкту

Створити простий та зручний інструмент для контролю замовлень на оренду одягу, щоб працівник студії міг швидко побачити:

які замовлення потрібно виконати сьогодні;
які замовлення заплановані на найближчі дні;
що саме потрібно покласти в кожну посилку;
кому та коли потрібно відправити замовлення;
які речі мають повернутися до студії.
Цільовий користувач

Основний користувач — власник або працівник студії оренди одягу, який щодня працює із замовленнями клієнтів.

Базові можливості
Додавання нового замовлення.
Збереження дати оренди та дати відправлення.
Збереження інформації про клієнта.
Перелік речей, які потрібно підготувати для замовлення.
Перегляд замовлень на сьогодні.
Перегляд майбутніх замовлень.
Перевірка статусу замовлення.
Позначення замовлення як підготовленого або відправленого.
Алгоритм роботи
Працівник додає нове замовлення.
Вказує ім'я клієнта та контактні дані.
Вказує дату оренди.
Вказує дату, коли потрібно відправити або підготувати замовлення.
Додає список речей, які потрібно покласти в посилку.
Система зберігає замовлення.
Щодня працівник відкриває список замовлень на поточну дату.
Система показує всі замовлення, які потрібно виконати сьогодні.
Працівник перевіряє список речей для кожного замовлення.
Після підготовки посилки замовлення отримує відповідний статус.
Після відправлення замовлення працівник позначає його як відправлене.
Після повернення одягу замовлення закривається.

Майбутній розвиток

У майбутньому проєкт можна розширити:

календарем замовлень;
нагадуваннями;
пошуком замовлень;
фільтрацією за статусом;
обліком речей у студії;
автоматичним формуванням списку для пакування;
повідомленнями про наближення дати відправлення.
