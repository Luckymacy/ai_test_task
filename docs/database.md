# Database

## Статус

База даних у поточній версії Dress Rental Planner ще не підключена.

Нижче описана запланована структура даних для майбутньої реалізації.

## Clients

Зберігає інформацію про клієнтів.

Можливі поля:
- id
- name
- phone
- telegram_username
- created_at

## Orders

Зберігає інформацію про замовлення.

Можливі поля:
- id
- client_id
- rental_date
- shipping_date
- return_date
- status
- notes
- created_at

## Items

Зберігає інформацію про речі, які входять до замовлення.

Можливі поля:
- id
- name
- category
- size
- status

## Order Items

Зв’язує замовлення з речами.

Можливі поля:
- id
- order_id
- item_id

## Зв’язки

Один клієнт може мати багато замовлень.

Одне замовлення може містити багато речей.

Одна річ може використовуватися в різних замовленнях у різні дати.

## Майбутнє підключення

Для бази даних у майбутньому можна використати PostgreSQL.

Підключення може зберігатися у змінній середовища:

DATABASE_URL=your_database_url_here

Реальне значення DATABASE_URL повинно зберігатися тільки у файлі `.env` і не комітитися в Git.
