# Security

## Секрети проєкту

У проєкті використовуються секретні змінні середовища, наприклад:

- BOT_TOKEN
- DATABASE_URL

Реальні значення секретів зберігаються у файлі `.env`.

Файл `.env` не повинен потрапляти в GitHub і доданий у `.gitignore`.

## .env.example

Файл `.env.example` містить тільки приклади назв змінних:

BOT_TOKEN=your_bot_token_here
DATABASE_URL=your_database_url_here

Він може зберігатися в GitHub, тому що не містить реальних секретів.

## Основні правила

- не комітити `.env`;
- не вставляти реальні токени або паролі у код;
- не публікувати секрети в README або документації;
- у разі витоку токена одразу відкликати його та створити новий.
